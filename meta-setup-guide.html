WhatsApp (Meta) Setup Guide

Everything you need to collect from the Meta (Facebook) console to deploy and run the Restaurant AI Host. Work top to bottom. Values you collect here are entered once in the installer (the guided web UI or the whatsapp-setup CLI); the installer auto-discovers what it can and wires the webhook for you.

Two things the installer does for you, so you do not have to hand-copy them: once you provide a business-scoped Access Token + Business ID, it discovers your WABA ID and Phone Number ID and lets you pick from a list; and after the deploy it sets the webhook callback URL, Verify Token, and field subscription in Meta automatically.

Prerequisite: a Meta app with the WhatsApp product

0

No API can create the app for you - this is a one-time manual bootstrap.

  1. Go to developers.facebook.com/apps and Create App (type: Business).
  2. In the app, Add Product → WhatsApp → Set up.
  3. Make sure the app is linked to a Business portfolio (Meta Business Manager).

You also need a verified Business and a WhatsApp Business Account with a phone number added. The temporary test number Meta provides works for first tests.

Step-by-step: collect each value

1

App ID public

A numeric id that identifies your app.

Where: App Dashboard → App settings → Basic → "App ID".

2

App Secret secret

Used by the webhook to confirm each incoming event was signed by Meta. This is not the access token - it is a different value with a different job.

Where: App settings → Basic → "App Secret" → Show.

Treat this like a password. The installer stores it in AWS Secrets Manager and never prints it.
3

Access Token secret

Authorizes sending messages and calling the Graph API. You have two options:

Option A - Temporary token (fastest, for a first test)

Where: WhatsApp → API Setup → "Temporary access token". It expires in 24 hours.

Option B - System User token (recommended, long-lived)

A System User token does not expire, so the deployment keeps working. The installer can automate creating this for you if you provide an admin-authorized token once; otherwise:

  1. Open Business Settings → Users → System users.
  2. Add a system user (role: Admin or Employee).
  3. Assign assets → your app and your WhatsApp Business Account (full control / manage).
  4. Generate new token → select your app → scopes whatsapp_business_messaging and whatsapp_business_management → set expiration to Never.
  5. Copy the token (shown once).
To list your WABA / phone number automatically, the token needs whatsapp_business_management. An App ID + App Secret alone is not enough for discovery.
4

Business (portfolio) ID public

Identifies your Business in Meta Business Manager. Give this to the installer and it will auto-discover the WABA and phone number under it (you pick from a list if there is more than one).

Where: Business Settings → Business info → "Business portfolio ID".

5

WABA ID & Phone Number ID auto-discovered

You normally do not need to copy these by hand - the installer discovers them from your Access Token + Business ID and lets you select. If you prefer to enter them manually:

Where: WhatsApp → API Setup shows the Phone number ID and the WhatsApp Business Account ID for the selected number.

6

Verify Token you invent it

This is the one value that does not come from Meta. It is just a shared secret for the webhook handshake: Meta sends it to your webhook, and your webhook checks it matches. Pick any random string (e.g. my-verify-7f3a9c2b), or leave it blank in the installer to have one generated for you. The same value must end up both in your deployment and in Meta's webhook config - the installer handles both sides.

After the deploy: wiring the webhook

The installer does this for you in its post-deploy step (or the whatsapp-setup "Post-deploy" flow): it sets the callback URL + Verify Token, subscribes to the messages field, and subscribes your WABA. The steps below are only for reference or manual setup.
  1. After deploying, the installer shows your webhook URL (like https://abc123.execute-api.us-east-1.amazonaws.com/prod/webhook).
  2. In the Meta app: WhatsApp → Configuration → Webhook → Edit.
  3. Paste the Callback URL and your Verify Token, then Verify and save.
  4. Under Webhook fields, subscribe to messages (and calls if you want voice).
If "Verify and save" fails, the Verify Token in Meta does not match the one stored in your deployment. Re-run the installer's WhatsApp step so both sides agree, then verify again.

Quick checklist

  • Meta app created, WhatsApp product added, linked to a Business portfolio
  • App ID copied
  • App Secret copied (kept private)
  • Access Token ready (temporary for a quick test, or a System User token to last)
  • Business (portfolio) ID copied
  • (Optional) WABA ID + Phone Number ID - or let the installer discover them
  • Verify Token chosen (or let the installer generate one)
  • Run the deploy, then let the installer wire the webhook and subscribe messages
  • Send a WhatsApp message to the number - the agent should reply
